Basic knowledge in Exploratory Data Analysis is very vital for this course.

Purpose

To equip students with the skills to enable them to perform basic statistical analysis using standard statistical software and interpret the results.

Objectives

By the end of the course the student should be able to:

  1. Use a Statistical Software

  2. Use a computer programme in estimation of the measures of central tendency and dispersion.

  3. Use a computer to estimate simple linear regression models

  4. Apply statistical computer packages for handling statistical techniques such as graphics, sampling variability. Computation of density, distribution and quartile functions for probability distribution.

Description

Introduction to R and Excel: Numeric and vector operations and importing data from spreadsheets like excel and SPSS. Measures of central tendency: Arithmetic mean, Harmonic mean, Geometric Mean, Mode, Median, Quartiles. Measures of dispersion: Range, Variance, Kurtosis, Skewness, Exploratory data analysis. Correlation: Pearson and Rank correlations. Simple Linear Regression, Computation of density, distribution and quintile functions for hyper geometric, binomial, Poisson, normal, exponential, Gomperz weibul, uniform, and Chi-square, beta and gamma distributions.

Teaching Methods

  1. Lecture: oral presentation generally incorporating additional activities, e.g. writing on a chalk-board, exercises, class questions and discussions, or student presentations.

  2. Practical: a laboratory experiment/session as a means of further actively involving students.
